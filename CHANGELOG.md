## Unreleased

- New crate `fs-starter-host` with the binary `fs-starter`: `fs-starter --description PATH` (or a bare PATH: a blueprint folder, a `forms/` folder or one file) opens the window of a program from its description without building the program. It uses `fs-forms-run` (git tag v0.0.4) as a library, so the words `--frontend`, `--style`, `--sample-data`, `--picture` are the ones of that crate; `--version`/`--help`/wrong words (exit 2) are the host's own, exit codes are those of `fs_starter::Exit`. The starter parts single instance, session, update, help and MCP are not built yet and are named once on stderr (`skeleton-part-pending`). Tests: CLI, element tree and picture tests of the real description of fs-tasks (copy in `tests/data/fs-tasks`).
- Auf Deutsch: Neues Crate `fs-starter-host` mit der Binary `fs-starter`: `fs-starter --description PFAD` (oder nur ein PFAD: Bauplan-Ordner, `forms/`-Ordner oder eine Datei) oeffnet das Fenster eines Programms aus seiner Beschreibung, ohne das Programm zu bauen. Es nutzt `fs-forms-run` (Git-Tag v0.0.4) als Bibliothek; `--version`/`--help`/falsche Woerter (Exit 2) sind die des Hosts, die Exit-Codes die von `fs_starter::Exit`. Die Starter-Teile Einzel-Instanz, Sitzung, Update, Hilfe und MCP sind noch nicht gebaut und werden einmal auf stderr genannt (`skeleton-part-pending`). Tests: CLI-, Elementbaum- und Bildtests der echten Beschreibung von fs-tasks (Kopie in `tests/data/fs-tasks`).

The code is unchanged; tests (all features) and clippy pedantic are green. Next: `fs-rpc` v0.0.4 without the crate; `fs-forms-bin` points at this repo.
